# List View Demo

A Flutter demo of `ListView.builder` showing how `reverse`, `padding`, and `itemExtent` change a scrollable list of household expenses.

## Run it

```bash
flutter pub get
flutter run
```

## Three attributes

- **`reverse`**: Flips the scroll direction so the first item starts at the bottom.
- **`padding`**: Adds space around the whole list. The slider changes it from 0 to 32px.
- **`itemExtent`**: Forces every row to the same height (56px), which speeds up layout for long lists.
